## v1.0.0
- Reveal map: show the whole world map by removing the map fog (display only, nothing saved; off by default).
- Death log: the cause of each death (creature, fire, poison, fall, drowning, ...), the last hits before it, and a history in the Stats tab.
- Food alert: warnings when an eaten food is about to run out or has run out, with optional "can eat again" and empty-slot notes; quiet while resting or indoors at a base.
- Config backups: save settings and waypoints to a dated folder, then import or delete them from the menu.
- Store all button under an open chest, sharing the storage window's keep rules (off by default).
- Auto-pickup filter: editing the whitelist / blacklist shows a grid of every item in the game beside the text box; click icons to add or remove names. The never-store list has the same grid.
- Default sign color: the text prompt now has a color panel beside it with ready-made colors and R / G / B sliders.
- Waypoints: choose one of the game's five map pin icons per waypoint; optional on-screen markers for the pins you place on the game's own map.
- Hotkeys can be changed in the menu (More → General).
- The menu and the storage window can be resized with a grip in their bottom-right corner.
- Side panels (sign editor, color panel, item grid) no longer cover the text box in a small window.
- Range circle on the ground while dragging a distance slider (storage, chest, sign search, radar, waypoint range).
